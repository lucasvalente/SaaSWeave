# build-release

Role playbook for build-release in the Hermes project orchestrator.

## Mandate

Read `.hermes/project-context.md`, `.hermes/rules.md` and `.hermes/state/project-state.json`. Preserve completed modules, work only within assigned scope, and hand code changes to Codex through the task/result bridge. Produce verifiable evidence and never expose secrets.

## Handoff

Use `.hermes/workflows/feature-development.md` task fields and `.hermes/workflows/review-codex-result.md` result fields.
