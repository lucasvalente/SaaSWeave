# Project context

Objetivo: criar um app builder SaaS brasileiro independente, capaz de gerar apps full-stack reais.

Golden Stack: TanStack Start, React 19, TypeScript strict, TanStack Router/Query/Form/Table, Tailwind CSS 4, shadcn/ui, Radix UI, Supabase, Zod, Motion e Paraglide JS (pt-BR/en/es).

Control Plane: TanStack Start, React, TypeScript, Hono, PostgreSQL, Drizzle, Redis, BullMQ, S3/R2, Better Auth, MFA, RBAC, Audit, OpenTelemetry, Playwright e Vitest.

Princípios: multi-tenant, fail closed, tenant isolation, segurança forte, código real, sem dependência do Lovable e sem alterar funcionalidades completas sem regressão comprovada.
